# HOW THIS CALENDAR WORKS

This calendar puts the two social media kits on a schedule. Each month has one Savvy theme. Wealth Code posts every Wednesday and the Savvy Playbook every Friday. Topics are matched to holidays, enrollment windows, and tax deadlines, so each post lands when the audience is already thinking about it.

| **Day**         | **Content**                                                           | **Notes**                                                                                 |
|-----------------|-----------------------------------------------------------------------|-------------------------------------------------------------------------------------------|
| **Wednesday**   | Wealth Code: Women's Edition carousel or single visual                | Wealth Code newsletter every other week, alternating with the Playbook (see each month)   |
| **Friday**      | The Savvy Playbook carousel                                           | Playbook newsletter every other week, alternating with Wealth Code; none on holiday weeks |
| **Once a week** | Reel or short video tied to that week's Playbook or Wealth Code topic | Post Monday or Tuesday so it doesn't compete with the anchor posts                        |
| **Once a week** | Story sequence: poll, answer, teaser, link                            | Use the inner-dialogue slide (Wealth Code) or a true/false (Playbook)                     |
| **Holidays**    | Simple greeting from a pre-approved batch                             | No financial content or promotion on holiday greetings                                    |

## Compliance Workflow

- Submit each week's full package (art, caption, on-screen text, newsletter) to compliance two weeks before the week starts. The date is in the last column of each month.

- Holidays slow down reviews. Send the Thanksgiving, December, and New Year batches early, by the dates noted.

- Send all holiday greetings as one batch in October so they're approved ahead of time.

- Topics marked "Drafted" already have copy from the five-package Playbook set and only need final review.

- Topics marked "Repurpose" reuse an approved post. Check with compliance whether re-posting or editing it needs a new approval.

- Log each approval ID and date, and post only from archived accounts.
